# Numidea Labs: private kit

Private material for Numidea Labs and the founder's personal page. Never copy it into the public site repository (Numidea.tech).

Start with TASKS.md: every open thread, its status, what it waits on and how to resume it.

| Folder | What is in it |
|---|---|
| marketing/ | Marketing and video plan (PLAN.md, strategy, channels, facts bank, scripts), the carousel series plan (azuki-carousel-plan.md), the coded video pipeline (pipeline/, without node_modules: npm ci), music made in code (music-lab/), the V01 trailer renders (out/v01) |
| stickers/ | The sticker and loop pipeline (render.mjs, runtime.js, pack.mjs, pack.json, scenes/, assets/) and the delivered WhatsApp pack and formats (out/_deliver) |
| magnific/ | Catalogue of the generated art (CATALOG.md, inventory.tsv, manifest-notokens.json), every render at full resolution (renders/, checked by SHA256SUMS-full.txt), contact sheets |
| hub-art/ | The personal hub's art: sources (src/), cleaned masters (masters/, pinned by MASTERS.sha256), the tools that made them (tools/masters.py, tools/loops.py), the brief and design plan, QA sheets |
| carousel/ | The miniature-world carousel script, the Canva carousel export |
| design-system/ | Source of the Numidea Labs Design System published in Claude |
| tools/ | Cut-out and contact-sheet helpers |

Rebuildable files are left out: node_modules, rendered frames, ProRes masters, WAV renders, review screenshots.
