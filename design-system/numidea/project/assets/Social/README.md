## Use

- Treat it as the reference for a wide card (1.91:1): text block left, one plate right, kicker, headline, conditions, label, nothing else.
- **It leads with the Aperçu headline, which is Gate B material.** Until Gate B opens, remove the link preview when posting a link to the site, or leave the link out where the preview cannot be removed, unless the owner decides the card may unfurl earlier (`marketing.md`).
- It is French only: English and Arabic links unfurl it too, until the site has pages of its own per language.

## Don't

- Don't post it as an image, crop it or edit it: it belongs to the site's build and changes only there.
- Don't copy its headline into a piece before Gate B, or without its conditions after.
