# Marks

There is **no drawn logo**. The brand's mark is the wordmark, set in type every time: « Num*idea* Labs » in the `logo` style (README, Type). This group holds the one drawn mark the site has, its favicon.

## `favicon.svg`

- **What it is:** the site's browser-tab icon, 64 × 64 px: an italic bold serif « N » filled with a teal-to-white-to-red gradient (#09d8c7, #eaf2f4, #bd0927), with a short red bar (#bd0927) to its right, on a rounded tile (14px corners) filled with a plum-to-navy radial gradient (#411e3a, #17364f, #0d1a2f). The letter is set in the system's serif fallback (Georgia), not in a brand face.
- **Inks:** several, fixed in the file; it is not a single-ink mark, so CSS colour does not change it. Its colours **predate the six themes** and are not tokens.
- **Where it is used:** as the favicon of the site's pages.

## Do

- Use it only where a small square icon of that kind is expected: a browser tab, a bookmark.
- Show it at its own proportions, on any ground (the tile carries its own background).

## Don't

- Don't use it as the logo on a post, a slide, an end card or a landing page: set the wordmark instead.
- Don't take its gradient or its colours into a design: gradient-filled text is banned, and colours come only from the theme tokens.
- Don't recolour it, enlarge it into a hero mark, or redraw it in a brand face. A new mark or a profile picture for the studio's accounts is the owner's decision.
