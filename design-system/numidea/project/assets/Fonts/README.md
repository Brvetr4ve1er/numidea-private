# Fonts

## `OFL.txt`

- **What it is:** the SIL Open Font License 1.1 covering Cinzel, Cinzel Decorative, Geist, Geist Mono and IBM Plex Sans Arabic, the faces in `fonts/`. It is the site's own licence file (`assets/fonts/OFL.txt`), copied unchanged.
- **What it allows:** use the faces in any piece. The licence does not restrict images, documents or videos made with them; it governs the font files themselves.
- **Where it goes:** keep it beside the font files whenever they are shipped (a landing page's font folder, a template handed to someone else). A post, a carousel or a deck exported as images or a PDF needs no notice.

## Don't

- Don't ship an edited font file under the face's original name: the licence reserves the names.
- Don't sell the font files on their own.
